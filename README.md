# 📌 Sobre o Projeto

A **SmartCam AI** é uma landing page inspirada em uma câmera inteligente com IA integrada aos dispositivos **JOVI**.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript puro**, com foco na prática dos principais conceitos de **Web Development**, sem o uso de frameworks ou bibliotecas externas.

---

# ✅ Requisitos Implementados

- [x] Manipulação dinâmica de elementos e eventos DOM  
- [x] Validação de formulários (contato + login)  
- [x] Login simulado com modal  
- [x] Utilização de `alert()`, `prompt()` e `confirm()`  
- [x] Slideshow com next/prev, dots e autoavanço  
- [x] Manipulação de imagens com CSS  
- [x] Criação e gerenciamento de eventos com DOM  
- [x] Navegação interativa com botões, tabs e scroll  
- [x] Projeto 100% JavaScript puro
